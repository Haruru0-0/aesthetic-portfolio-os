# Wallpapers

One folder per device and screen:

| Folder | Used by |
|---|---|
| `desktop/home/` | The desktop. Every image here appears in the wallpaper switcher (command palette and right-click menu); see its README |
| `desktop/lock/` | The desktop lock screen. Every image here appears in the lock screen settings button and the home screen pickers |
| `mobile/home/` | The mobile home screen. Every image here appears in the Wallpaper tile sheet (Home tab) |
| `mobile/lock/` | The mobile lock screen. Every image here appears in the lock screen button and the Wallpaper sheet (Lock tab) |

All four folders are picked up automatically. Use landscape images for `desktop/*` and portrait ones for `mobile/*`.
