# Architecture

See [[features-built]] and [[gotchas]].

A portfolio site that looks like a desktop operating system. Vite + React + TypeScript, TanStack Router (generated `routeTree.gen.ts`), Tailwind CSS, GSAP, `@dnd-kit` for dragging, Vitest for tests.

- `src/routes/`: `__root.tsx`, `index.tsx`, `desktop.tsx` (the desktop).
- `src/components/`: `Desktop`, `Window`, `Taskbar`, `MenuBar`, `Icon`, `MobileIcon`, `SnapMenu`, `MusicPlayerWidget`, sound, audio, achievement and theme contexts; `ui/` (shadcn).
- `src/components/pages/`: the window contents: `about-me`, `resume`, `projects`, `blog`, `links`, `contact`, `terminal`, `achievements`.
- `src/data/blog-posts.ts`: **generated** by `scripts/fetch-blog.mjs` from `https://ahmadkanaan.hashnode.dev/rss.xml`. `src/lib/hashnode.ts` re-exports it as `fetchBlogPosts()`.
- CI: `.github/workflows/mirror-to-gitlab.yml` (mirror on push and nightly) and `refresh-blog.yml` (daily 04:23 UTC; commits `src/data/blog-posts.ts` if the feed changed).
- `src/data/profile.ts`: single source for name, role, years, email, phone, location, GitHub, LinkedIn, blog, resume PDF and photo paths, skills and interests; About, Resume, Contact, Links and Terminal read from it. `src/lib/autoplay.ts` builds carousel autoplay (5s, stops on interaction or hover, off under reduced motion).

## Scripts
`yarn dev` (port 3000), `yarn build` (runs `fetch-blog` first via `prebuild`, then `vite build && tsc`), `yarn serve`, `yarn test`, `yarn fetch-blog`.
- `components.json` registries: `@react-bits`, `@magicui`, `@aceternity`, `@8bitcn`, `@pixelact-ui`, `@retroui`, `@cult-ui` (URLs checked 2026-11-12). Review third-party components after `shadcn add`: they may hardcode `@/components/ui` imports and other icon sets.
- `src/components/ui/8bit/` holds components installed from `@8bitcn` (timeline1, xp-bar, quest-log and their parts: accordion, card, scroll-area, label, progress; unused ones were removed), styled by `8bit/styles/retro.css` (uses the site font, no Google Fonts). Plain shadcn `dialog`, `command`, `accordion` and `scroll-area` were added beside them; the dialog z-index is raised above desktop windows.
- `src/components/GlassPanel.tsx` is the shared liquid-glass surface (`.glass-panel` in `styles.css` darkens the tint); used by `CommandMenu.tsx` and `DesktopContextMenu.tsx`. `ui/terminal-animation.tsx` (@cult-ui) and `ui/magic-card.tsx` (@magicui, recoloured to `--card-bg` and the cute palette; adds `motion`) were installed from registries.
- `GlassPanel` now renders `GlassSurface.tsx` (@react-bits) by default (`variant="surface"`; `"classic"` is the old CSS glass). The desktop wallpapers are `<img>` elements; `wallpaper-context.tsx` passes the active one (desktop or mobile, by `isDesktop`) to `GlassPanel` as the GlassSurface `backdrop`, so Firefox/Zen and Safari use WebGL refraction while Chromium uses SVG refraction. It is blue tinted (24% tint layer) and keeps GlassSurface's default border band and distortion; the dock and menu bar grow on hover (`.dock-glass` in `styles.css`, `group-hover:py-3.5` in `MenuBar.tsx`). Used by the search panel, right-click menu, menu bar, dock and its overflow menu, the sound and theme dropdowns, the desktop achievement toast, the mobile folder and settings bar, the music "click to play" pill and mobile playlist panel, and the lock screen card and cancel button (the lock screen wallpapers are `<img>` elements too and feed `WallpaperContext`, but its overlay has `backdrop-blur-md`, so in Zen the WebGL card samples the unblurred image). Still on the CSS `.liquidGlass-*` glass (restyled blue with a thinner rim): desktop icons (on purpose), mobile icons, the playlist rows and the mobile achievement toast (GSAP resizes it). Many small GlassSurfaces would mean many filters and WebGL contexts.
- Assets are grouped in `src/assets/` (`app-icons`, `wallpapers`, `mascots`, `mobile-widgets`, `music/ui`, `music/tracks`, `projects`; see its README). `wallpapers/` is split by device and screen: `desktop/home` (the switcher), `desktop/lock`, `mobile/home`, `mobile/lock`. Desktop home wallpapers are picked up by `import.meta.glob` in `src/lib/wallpapers.ts` (file name becomes the label; `DEFAULT_ID` is `lilies-night`). `WallpaperChoiceContext` (in `wallpaper-context.tsx`) exposes the list and `select`/`next`. All images under `src/assets` are WebP (animated GIFs became animated WebP); `public/` icons stay PNG/ICO for the manifest.
- `Taskbar.tsx` drives the dock magnification: `DockMouseContext` carries a cursor-x `MotionValue`, and each `DockButton` derives its size from its distance to the cursor (`useTransform` + `useSpring`). `.dock-magnify` in `styles.css` bottom-aligns the icons and replaces the old hover padding grow. `GlassSurface`'s ResizeObserver is throttled to once per 120ms so a resizing panel does not rebuild its displacement map every frame.
- `GlassPanel` picks glass settings by browser: Firefox/Zen and Safari (WebGL path) keep GlassSurface's default `borderWidth` and `distortionScale`; Chromium (SVG path) gets `borderWidth` 0.12 and `distortionScale` -250 so its edge refraction is as visible as the WebGL one. The dialog overlay is `bg-slate-950/35` and the search panel has a `border-white/40` rim and a deeper tint (`rgba(12,55,115,0.62)`).
- `src/lib/wallpapers.ts` now builds two lists, `WALLPAPERS` (`desktop/home`) and `MOBILE_WALLPAPERS` (`mobile/home`), with separate storage keys (`portfolio-wallpaper`, `portfolio-wallpaper-mobile`); the glob options must be written inline for Vite. `Desktop.tsx` provides the active set through `WallpaperChoiceContext` (by `isDesktop`). New: `MobileControlTiles.tsx`, `WallpaperPicker.tsx` (mobile sheet) and `IconTile.tsx` (a tile that behaves like the app icons: glass on hover, icon scale, sounds); `SoundSettings` and `ModeToggle` take `variant="tile"`. `MobileSettingsBar` was removed.
- `src/lib/wallpapers.ts` now has four sets (`WallpaperKind`: `desktop`, `mobile`, `desktop-lock`, `mobile-lock`) read from `src/assets/wallpapers/{desktop,mobile}/{home,lock}/`, each with its own storage key and default (`lilies-night`, `jellyfish`, `blossom-streetlight`, `blossom-street`). `useWallpaperSelection(kind)` (`src/lib/use-wallpaper-selection.ts`) holds one set's selection. `WallpaperChoice` has an optional `lock` set, provided by `Desktop.tsx` per device. `routes/index.tsx` reads the lock selection itself, with `LockScreenSwitcher.tsx` for the button and panel, and `WallpaperGrid.tsx` is the shared thumbnail grid.
